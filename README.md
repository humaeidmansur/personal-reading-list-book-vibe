# Personal Reading List 📚

A responsive book discovery and personal reading list application built with **Next.js, React, TypeScript, and Tailwind CSS** as part of the DevConnect internship.

## 🚀 Features

* Browse books and view book details.
* Add books to your personal reading list.
* Remove books from your reading list.
* Handle loading, error, and empty states.
* Provide clear feedback and guidance for users.
* Responsive layout for mobile and desktop.
* Keyboard navigation and visible focus indicators.

## 🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* React Toastify
* Recharts (where used)

## ⚙️ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/humaeidmansur/personal-reading-list-book-vibe.git
```

**2. Navigate to the project directory**

```bash
cd personal-reading-list-book-vibe
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

**5. Build for production**

```bash
npm run build
```

## 🧪 DevConnect Acceptance Criteria

The application should demonstrate the following states without requiring source-code changes:

| State       | Expected behavior                                                        |
| ----------- | ------------------------------------------------------------------------ |
| **Loading** | Displays a clear loading indicator while data is being fetched.          |
| **Error**   | Explains what failed and provides a useful next step.                    |
| **Empty**   | Explains that the reading list is empty and offers a clear first action. |

These states should be visually and textually distinct. The README and application must document how reviewers can access each state.

## ♿ Accessibility

* Keyboard-operable interactive controls.
* Visible focus indicators.
* Clear messages and button labels.
* Responsive layout, including at **320px** screen width.
